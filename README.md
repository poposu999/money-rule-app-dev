# 家計簿アプリ

## ver.47.86
- 支出ペースを「使った金額」と「今月の経過」の2本のメーターに分離
- 2本のメーターは同じ幅・同じ開始位置・同じ終了位置に統一し、上下を近接配置
- 上段に予算使用率、下段に月の経過率と当日の日付を表示
- 日数側には 0日 / 10日 / 20日 / 月末 の目盛りを表示
- 支出と日数の差を「○ポイント先行 / ○ポイント余裕 / ほぼ同じペース」で明示
- Ver.47.85で追加した1日あたりの目安、目安との差、月末予測の補足は維持
- index.html / app.js / sw.js / キャッシュ指定 / アプリ下部のバージョンを ver.47.86 に統一
