# 家計簿 Web MVP ver.47.1

現在のバージョン：**ver.47.1**

## ver.47.1の変更点
- 支出メーターに月内経過日数のメモリ（1日・10日・20日・月末）と現在日付のマーカーを追加。月末は28〜31日を自動判定。
- 支出メーターの予算使用率を100%超でも実際の割合で表示。
- 支出・予定支出・固定費のメモをタップすると全文をポップアップ表示。
- 予定支出・固定費の入力メモを記憶しない仕様を維持。
- 「支出に確定」「支払済み」の文言を以前の表示に復元。
- 「支出に確定」「支払済み」を「編集」「削除」と同じサイズに調整。
- 確定・済みボタンを編集・削除ボタンと同サイズに調整。
- 使いすぎ予報の文言、スマートフォンの日付入力欄・テーブル表示、グラフカードの見た目を調整。

## ver.47の変更点
- 新規状態での初期値を調整（前月の収入25万円、最低限の手取り20万円、貯金目標5万円、超過分のお小遣い60%、超過分の貯金40%、ボーナス0円）
- 収入・家計ルールの入力欄に「例）」のプレースホルダーを追加

## ver.45の変更点
- 入力タブの並びを「支出 → 支出予定 → 固定費」に変更
- 固定費のカテゴリボタン「その他 その他」を「その他」に修正
- 今月の支出の編集画面から、支出を今月の予定支出へ戻せる機能を追加
- 固定費一覧の「支払済み」から、今月分を「支出に確定」前の状態へ戻せる機能を追加

## ver.47
- Service Worker / PWA対応を追加。
- 一度オンラインで読み込んだ後は、機内モードなどのオフライン状態でもリロードして利用できるように、アプリ本体を端末側へキャッシュ。
- オンライン復帰時は最新のHTML/CSS/JavaScriptを取得し、古いキャッシュを更新。
