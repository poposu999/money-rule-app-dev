# 家計簿 ver.50.1（検証版）

## この版の変更点（Issue #1）

- ホーム予算カードを「今月の予算状況」に統一し、残り予算と日額を横並びにしました。
- 実支出・未払い予定支出と未払い固定費の合計・残り予算を連続バーと金額で表示します。
- 超過額は正の金額、当月・未来月の超過時の日額は0円で表示します。過去月は日額を表示しません。
- 支出前の使える予算がマイナスの場合は「予算不足」とし、実支出・支払い予定を含む不足総額と専用の補足文を表示します。日額と下部残り予算は0円です。
- 使える予算がちょうど0円の場合は予算不足にせず、支出が発生した場合は「予算超過」とします。
- 予算上限0円以下は空バー、収入・ルール未入力は未計算として表示します。
- 旧メーターの目盛りや重複説明を削除し、ライト／ダーク両テーマに対応しました。

既存の予算計算・schemaVersion 50・保存キー・リンク・移行・バックアップ互換性・Service Worker仕様は変更していません。
本番版は変更していません。developへの統合・公開には別途GOが必要です。
