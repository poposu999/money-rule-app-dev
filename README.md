# 家計簿 Web MVP ver.47.5

現在のバージョン：**ver.47.5**

## ver.47.5の変更
- 「今月の支出」と「固定費一覧」のメモ欄を広くし、長いメモを確認しやすく調整。
- カテゴリ・金額・操作ボタンを右側へ寄せ、列の視認性を調整。
- 固定費一覧の支払日表示を「毎月○日」から「9/10」のような月/日形式へ変更。月は現在月、日付は登録した支払日を表示。
- 固定費の31日設定など、当月に存在しない日付は当月末日に補正して表示。
- 家計簿データ（moneyRuleAppV2）は変更・削除しない。
