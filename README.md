# 家計簿 ver.49.04（検証版）

## ver.49.04の変更点
- 年間レポートにメモの部分一致検索・カテゴリ単一選択を追加。検索ボタンで適用し、件数・合計・各月の小計を表示。
- 年切替時は適用済みの検索条件を保持。条件クリアで通常表示へ戻り、月の明細を開いた初期状態に戻す。
- 支出明細に「すべて開く／すべて閉じる」を追加。検索条件・開閉状態は再読み込み後へ保存しない。
- 年間明細をホームと同じテーブルに統一し、既存の支出編集画面を利用可能に。保存後は年間レポートの表示位置を維持。
- 検索結果の明細を編集して条件から外れても、次の検索まで行を維持。削除・予定支出や固定費への差し戻しは即時反映。
- 年間支出合計の下に月平均と対象期間を追加。最初の実支出月から今年は現在月、過去年は12月までを対象とし、途中の支出0円月も含める。対象データなし・未来年は「—」。
- 検索によって年間支出合計・グラフ・月平均は絞り込まない。
