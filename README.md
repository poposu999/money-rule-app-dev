# 家計簿 ver.49.13（検証版）

## ver.49.13の変更点

- 予定支出・固定費と実支出の双方向編集、支出への確定、未払いへの復帰、月またぎ処理を統合しました。支払済みの元の行は一覧に残ります。
- 通常項目・並び順は保存で確定し、支払い状態は必要な確認後に即時反映します。未保存変更は「保存して実行／破棄して実行／編集画面に戻る」から選べます。
- 固定費に項目別の「この月だけ／この月以降」の変更履歴を追加し、支払済みの実績と継続設定を分離しました。
- 新保存形式への移行、旧バックアップの復元、整合性チェック、バックアップ保存・変更前後確認を伴う手動修復を追加しました。
- 予算・グラフの集計と年間検索結果の保存後更新を統合し、問題のある月には「集計要確認」を表示します。
- 「＋ 記録」を予算表示の直下へ移動しました。

## 初回移行

移行前にバックアップファイルを書き出し、ファイルアプリなどで実際の保存を確認してください。保存確認後に初めて移行します。移行前の検証データは削除せず、新しい保存領域への書き込み・読み戻し検証後に切り替えます。

ver.49形式と、安全に識別できるver.48系バックアップを復元できます。識別できないID・不正な日付などは変換を中止し、異常なリンクは無断で修復しません。本番の保存データは変更しません。

## 実機確認

iPhoneでの表示・キーボード・ファイル保存と、実際のバックアップを使った確認は利用者による検証対象です。
