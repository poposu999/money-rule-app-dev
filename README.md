# 家計簿 ver.50.2（検証版）

## この版の変更点（Issue #3）

- データ管理のバックアップ欄に、通知ON/OFF、7・30・90日の通知間隔、最終バックアップ日時を追加しました。
- 通知は初期OFFで、OFFからONにした際の間隔は30日です。設定は保存ボタンなしで端末へ保存します。
- 端末ローカルの日付で期限を判定し、ホームの月選択直下に通知します。「今日は閉じる」を押した日だけ非表示にします。
- ホームとデータ管理は同じ書き出し処理を使用します。「保存できました」の確認後に、そのJSONのexportedAtを記録します。
- 復元時は正常かつ未来でないexportedAtを採用し、それ以外は記録なしにします。日時の異常だけで家計データの復元を拒否しません。
- 通知情報は専用の端末設定キー moneyRuleDevBackupReminder に保存し、家計データのバックアップには含めません。復元時も端末の通知ON/OFF・間隔・当日の非表示状態を維持します。
- Web Push、自動保存、バックグラウンド通知は行いません。

schemaVersion 50、既存の家計データ保存キー・保存形式・リンク・計算・旧バックアップ互換性・検証Service Workerの動作を維持しています。
本番環境は変更していません。developへの統合・公開には別途GOが必要です。
