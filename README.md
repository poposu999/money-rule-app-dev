# 家計簿 ver.49.05（検証版）

## ver.49.05の変更点
- 「収入・家計ルール」ページに、共通ホイール式の年切替と各1〜12月の一覧を追加。
- 収入を実際の受取月で表示。給与・ボーナスを分けて編集し、年間収入合計を表示。未入力と登録済み0円を区別。
- 既存の収入保存先・予算計算式を維持し、受取月の翌月予算へ反映。12月収入は12月に表示し、翌年1月予算から参照。
- 家計ルールは月の行をタップして編集し、保存時に「この月だけ／この月以降」を選択。単月例外は翌月へ持ち越さず、未来の設定済み変更・例外を保持。
- ルール変更月だけラベルを表示し、変更詳細は編集画面に表示。今年の現在月を薄く強調。
- 既存の月別ルールを予算結果が変わらない形で引き継ぎ、追加のルール情報をバックアップ・復元・整合性チェックに対応。
- ホームの暫定収入・家計ルール入力を撤去し、設定場所を新ページへ一本化。
