# 家計簿 ver.49.14（検証版）

## この版の変更点

- ［＋ 記録］をホーム右下の固定表示に戻し、予算直下から削除しました。
- 編集画面内の支払い状態は入力・並び順と同様に保存まで仮変更とし、キャンセル・×・背景タップで破棄します。必要な確認後に一括保存します。
- 一覧からの支出確定は、従来どおり確認後にその場で反映します。
- 通常の取消・削除確認を、対象名・金額・支払日・影響する月が分かる表示へ変更しました。手動修復の安全確認は維持しています。
- 固定費編集の支払い操作、削除エリア、最下部のキャンセル・保存を区切りました。保存ボタンは画面下端に固定しません。

保存形式はschemaVersion 50のままです。保存キー・移行・バックアップ互換性は維持し、再移行・初期化は行いません。

検証環境用の更新です。本番版は変更していません。
