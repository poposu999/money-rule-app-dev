# 家計簿アプリ

## ver.48.03
- Ver.49に向けた月別管理の検証版を開始し、過去・現在・未来の月切り替えと年月選択を追加
- 収入・ボーナス・家計ルールを月別データとして管理し、未入力状態と0円入力済みを区別
- 支出・予定支出・固定費を選択月ごとに登録・編集できるようにし、月をまたぐ移動と由来情報の保持に対応
- 固定費を開始月・変更履歴・支払済み月で管理し、1〜31日と「月末」の支払日に対応
- 今月・過去月・未来月で予算計算と支出ペースの表示を切り替え、今月は自由支出のペースで判定
- カテゴリ別・日別・月別グラフを、実支出・予定支出・未払い固定費の積み上げ表示へ変更
- Ver.48系データからVer.49形式への移行画面、移行前バックアップ、変換検証、再移行フローを追加
- Ver.49形式バックアップの置き換え復元と、復元不能時の承認付き部分復元に対応
- 検証環境を常時識別できる表示を追加し、PWA名も検証環境用に分離
- データ整合性チェックを追加し、重複ID・不正日付・由来リンク・固定費履歴・要確認データを検出
